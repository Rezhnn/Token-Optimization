# Contributing to FinOps Token Optimization

First off, thank you for considering contributing to this project!

## How Can I Contribute?

### Reporting Bugs
- Use the **Bug Report** issue template.
- Provide a clear test case or query that triggers incorrect zone resolution.

### Suggesting Enhancements
- Use the **Feature Request** template.
- Explain the token saving potential of the proposed change.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. Add or update files under the `skills/finops-zones` structure.
3. Ensure any changes to the template are copied across all ignore files.
4. Update `HYBRID_RUNTIME_SPEC.md` if any rules change.
5. Verify changes with a local installation using `install.sh` or `install.ps1`.
6. Submit a pull request.
